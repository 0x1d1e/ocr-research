00 / executive contract

What this specification commits to

Objective. Produce an end-to-end trainable OCR/document-understanding model that consumes page images and emits text lines, semantic roles, reading order, table cells, key/value associations, and structured outputs while keeping the inference model within 10 MB of FP32 weights.

Principle. Quality and actual CPU latency outrank incremental weight reduction. A small model that misses Khmer combining marks, mishandles nested document elements, or executes dozens of unnecessary OCR sequences fails the objective.

Mandatory deliverables

  • Versioned PyTorch model and tokenizer
  • Document annotation schema and converters
  • Deterministic training/evaluation harness
  • Structured JSON + HTML/Markdown export
  • CPU benchmark and ONNX parity report
  • Reproducible validation artifacts

Explicit non-goals for first release

  • Translation, summarization or VLM dialogue
  • Handwriting as a launch guarantee
  • 100% fidelity on arbitrary documents
  • Assuming CoreML/TFLite compatibility
  • GPU-only performance claims
  • Autonomous online self-training

Evidence status

The provided material reports a 1,524,997-parameter fused PrismOCR v3 and targeted toy tests. Full reproducibility was not established from the pasted, formatting-damaged code. V4 numbers below are design limits or proposed gates, not achieved experimental results. No trained OCR quality or real CPU latency has been supplied.

Two detector heads are the architectural split; the region head contains typed instance queries for regions and cells, without cross-type NMS that would suppress a table and its contained cells. This is distinct from merely replacing one global heatmap with two identical single-channel maps.

Design constraints

  • Retain the v3 multi-scale anisotropic backbone initially, so changes can be attributed to the proposal and OCR redesign.
  • Do not attach OCR computation to structural-only boxes. Text inside a table cell is recognized as one or more text-line instances and associated to that cell.
  • Keep positional/feature dimensions explicit. The reference width is D=160; changing it is an ablation, not a hidden implementation detail.
  • Any extra decoder parameters must remain within the actual FP32 byte ceiling and have a measured quality/latency justification.

05 / detection

Detection and proposal generation

Text-line head

  1. Produce stride-4 or stride-8 confidence logits, box geometry, and semantic line embeddings from shared features.
  2. Train with integer-anchored Gaussian targets or a validated equivalent, ensuring non-empty pages with representable centers have positive supervision.
  3. Define local maxima using a bounded neighborhood and calibrated confidence threshold. Stable tie-breaking is allowed only after candidate validity is established.
  4. Apply spatial deduplication to same-stream duplicates. Do not suppress related region/cell instances from the other head.
  5. Return at most Kt accepted line proposals plus a validity mask. Capacity overflow is counted.

Flat-map invariant

On a uniform 0-logit map (sigmoid=0.5), the detector must not claim any accepted text object under a calibrated threshold above 0.5. A custom threshold is permitted, but it must be fixed on validation data and tested on blank, gradient and plateau inputs.

Region / cell head

Use a small typed query decoder or equivalent instance head, initially with a configurable Kr=64 queries. Queries may represent a table and its constituent cells even when their bounding boxes are nested. Matching is type-aware; only duplicates of the same kind may be removed. Relation edges express containment rather than encoding all hierarchy in a single foreground heatmap.

Capacity policy. Kt and Kr are ceilings, not assumed document counts. Measure 95th/99th percentiles on the real corpus and choose defaults that fit the weight/runtime budget. For overflow, process overlapping tiles and merge geometrically instead of discarding tail objects.

06 / supervision

Matching and teacher forcing

One assignment per stream per forward

Compute Hungarian assignments from the same detached prediction snapshot that will be used by OCR sampling and all downstream losses. Persist the resulting MatchSet in the forward result. The loss module must not recompute a potentially different mapping.

MatchSet = {
  matched_gt_idx: LongTensor[N],
  matched_pred_idx: LongTensor[N],
  gt_count: int,
  valid_pred_count: int,
  unmatched_gt_idx: LongTensor[M-N],
  candidate_quality: FloatTensor[N],
  assignment_coverage: float,
}

# Pseudocode: pure matching, explicit absence handling
candidates = pred[mask]
cost = w_cls*C_class + w_box*C_box + w_iou*(1-IoU)
assign = hungarian(cost)                 # min(M,Kvalid), no crash on empty
accepted = validate_geometry(assign)    # NOT merely "a match exists"
match_set = freeze(assign, accepted)
loss = train_from(match_set)
ocr_boxes = schedule_gt_boxes(match_set, ratio=alpha)
assignment_coverage = N_assigned / M_gt (diagnostic only) proposal_recall@τ = N_unique_GT_with_accepted_candidate(IoU≥τ) / M_gt

For rotated boxes, use rotated polygon IoU; for very thin lines also report center-distance/height-normalized tolerances as secondary measurements. Match cost must be independent of non-finite values and robust to identical costs. Treat M=0, K=0, and M>K as first-class cases.

Teacher-forcing policy

  • Apply GT box interpolation only to matched proposal slots; preserve prediction-to-node identity.
  • Training uses scheduled sampling (alpha from 1 toward 0) based on a declared training step schedule, not hidden heuristics.
  • For early training with poor proposals, optional GT query injection is permitted as a separate, flagged experiment; disable it for validation/inference.
  • Do not accept implausibly distant assignments as successful detection, even if they receive auxiliary regression gradients.
  • One consistent mapping governs box regression, semantic role loss, CTC text targets, and relation endpoint remapping.

Unmatched supervision

If a GT object has no valid candidate, record it as a detection miss and continue optimizing dense detection/objectness targets. Do not attach its text to an unrelated OCR node merely to keep the CTC batch full. Reject batches only for actual data-contract violations.

07 / recognition

Sparse OCR and CTC recognition

Selection contract

Run recognition on text-line candidates only. At inference, OCR inputs must satisfy text_mask & (text_score ≥ calibrated_threshold), optionally after additional lightweight line-role filtering. At training, include matched text proposals and explicitly sampled hard negatives only when a defined recognition-negative objective is enabled.

Flatten accepted proposals across the batch into an actual compact list of length Ntext. Never allocate or execute recognition over fixed B×Kt slots and only mask the result afterward. Preserve per-line metadata for scattering decoded text to original document IDs.

Oriented feature sampler

Retain v3's five-row bilinear sample over stride-4 glyph features. Sample a grid of P_h=5 rows by L_i frames per line; rotate/scale by its normalized box orientation and collapse rows with a learnable vertical operator. Verify alignment between normalized box coordinates and grid_sample(..., align_corners=False) pixel-center conventions.

P_i ∈ ℝ[D × 5 × L_i] → vertical collapse → S_i ∈ ℝ[L_i × D] T_min(y) = len(y) + count(y[j] == y[j-1] for j = 1…len(y)-1)

Adaptive sequence lengths

Use L∈{64,128,160,256} as initial configurable length buckets, subject to actual alignment and performance results. Training may assign a bucket from GT transcript lengths; inference must choose from observable image geometry/recognizer predictors, never the hidden GT text. Monitor long-line failure and bucket occupancy. If minimum frames exceed the highest supported bucket, split at verified line segmentation boundaries or mark unsupported; never silently truncate a full-line label.

Vocabulary and Unicode

  • Maintain blank_id=0, reserve explicit unknown handling, and version a fixed vocabulary artifact with SHA-256. Begin with the reported v3 512-class design but rebuild the remaining entries based on corpus coverage.
  • Include Khmer base letters and combining marks; preserve canonical transcript provenance. Unicode NFC may be evaluated as a controlled normalization policy, never applied invisibly.
  • Before freezing vocabulary, measure unknown rate per language, document subtype, symbol category, and currency usage. Unknown characters must emit visible replacement/error metadata, not disappear on decode.
  • Record raw CER and any normalized CER separately, with explicit normalization steps. Score Khmer marks and coeng sequences as a dedicated error slice.

CTC supervision

Validate T_min(y) ≤ L before calling the loss. Set zero_infinity=False to surface invalid alignment assumptions and check loss/gradient finiteness. If a line cannot be supervised honestly, log ctc_rejection_reason and its sample ID, then split, re-bucket or exclude through a declared data policy. Do not use truncation as a fallback.

Decode policy

Greedy CTC decode is the initial deterministic default. Optional beam search or lightweight language-aware reranking is a separate experiment. Keep original per-frame logits/confidence available for diagnostics; decoded string probability must not be misrepresented as calibrated sequence confidence without validation.

08 / document graph

Document graph and reading order

The document graph connects stable line:, region:, and cell: instance IDs. A single index space is permitted internally, but endpoints must retain their type. Graph predictions are sparse and masked; relation classes have an explicit NULL candidate rather than abusing diagonal self-links to represent absence.

RelationAllowed source → targetConstraint
NEXTLine → line, within same reading-order scopeAt most one outgoing edge; no cycles after resolution
PARENTLine/cell/region → region or cellNo self-links; must be acyclic and geometric-compatible
KV_VALUEKEY line → VALUE line or value-bearing regionTyped target and one-to-many policy explicit
RIGHT_CELLCell → sibling cell of same tableMust be horizontally ordered; cannot cross rows without evidence
CONTAINSRegion/cell → line/cell/regionDerived from validated parent edges or annotations

Prediction and decoding

  1. Construct embeddings for valid line and structure instances only. Use key-padding masks for variable-length batched attention; zero out padded query outputs before losses.
  2. Score type-valid edge candidates plus NULL, with candidate generation constrained by page, document grouping, and geometric plausibility.
  3. Resolve NEXT using confidence-aware cycle handling, then stable topological ordering with geometry only as a fallback.
  4. Resolve PARENT / containment, rejecting cycles and invalid parent types. Prefer authoritative table membership where cell annotations exist.
  5. Return edge confidence and explicit reason codes for suppressed/ambiguous relations.

Do not assume a global top-to-bottom ordering is adequate for two columns, marginalia, mixed Khmer/English flow, or vertical labels. Evaluation must include multi-column and tables with independent line-order scope.

Reading-order invariant

Each active text line appears exactly once in the final reading-order output, unless explicitly tagged as a duplicate removed during tile stitching. A cycle must be resolved deterministically and logged; the decoder must not hang, silently drop nodes, or invent a missing line.

09 / structured decoding

Tables, cells and key-value extraction

Grid reconstruction is constrained, not a side effect of overlap heuristics

Detect table and cell instances, associate cells with the correct table, infer row and column tracks, and solve a non-overlapping placement problem. Cell geometry, learned right-neighbor signals and learned row/column affinities inform placement. A valid solved grid must never have conflicting cell origins or overlapping occupied slots.

  1. Group. Assign a cell to at most one parent table, with NULL for unassigned cells. Prevent joining adjacent tables merely because their bounding boxes are near.
  2. Infer tracks. Prefer learned row/column indices or separator proposals; use interval clustering as fallback. Require monotonically sorted tracks.
  3. Assign spans. Infer (row, col, rowspan, colspan) for each cell; nonnegative origins and strictly positive spans are mandatory.
  4. Resolve conflicts. Optimize global consistency or report a structured table-error state. Never overwrite cell_by_origin[(r,c)] without detecting a collision.
  5. Assemble text. Attach contained recognized text lines to each cell and order those lines. A line should not be duplicated across cells unless annotations explicitly support that duplication.
  6. Render. Emit semantic <th>/<td> based on predicted/annotated header status, not an assumed first header row. Use escaped text and true HTML row/column spans.
For any distinct cells a, b: OccupiedSlots(a) ∩ OccupiedSlots(b) = ∅ For each cell: 0 ≤ row, col; rowspan ≥ 1; colspan ≥ 1 End coordinates must remain within the declared table grid.

Markdown lossiness

Standard Markdown tables cannot faithfully represent rowspan or colspan. For nontrivial spans, the Markdown export shall embed sanitized HTML or explicitly annotate the loss of structure. Never claim a pipe table with [2x3] labels is structurally equivalent to HTML.

Key/value extraction

Only type-compatible links may form pairs. Normalize display keys separately from their original source text, preserve original Unicode, and keep duplicate keys as an array of entries instead of overwriting them in a dictionary. Return source/target IDs, confidence, page and reading order for auditability.

Renderer safety

Escape recognized content before embedding into HTML, including angle brackets, ampersands and quotes. Never treat OCR output as trusted markup. Schema output is the source of truth; HTML and Markdown are derived presentations.

Numerical requirements

  • Loss and gradient tensors must remain finite in FP32 and mixed-precision training.

Split and leakage policy

Split by originating document and, where possible, issuer/template family—not random crops or lines. All pages and augmentations of one document remain in one split. Keep a frozen final test set, a tuning validation set, and a separate synthetic sanity suite. Record near-duplicate fingerprints. Never tune thresholds on the final test set.

Label QA

  • Strict schema validator checks polygon winding, nonzero area, image bounds, stable IDs, normalized Unicode policy, and relation endpoints.
  • All table spans must describe a consistent occupancy grid, or be flagged annotation_ambiguous and excluded from grid supervision with a log entry.
  • Document reading order is annotated in intended logical order; unannotated relations are distinct from explicit NULL.
  • Persist annotation version, source class, license/permission metadata, reviewer, and a checksum. Do not include raw sensitive document images in public logs.

Augmentations: apply coupled image/geometry transforms (rotation, crop, warp, scale) with updated polygons, then validate. Photometric changes must not erase critical Khmer diacritics by default. Augmentation strength and probabilities are recorded.

Benchmark protocol

  1. Publish CPU model, operating system, runtime/compiler versions, batch size, thread configuration, affinity, precision and power profile.
  2. Run warmup iterations (minimum 30 for representative shapes) and timed iterations (minimum 100 per test case), reporting p50, p95 and throughput. Increase repetitions when variance is high.
  3. Separate preprocessing, backbone, detector, recognizer, graph/table decoder and total wall-clock latency. The end-to-end measure must include all enabled stages.
  4. Use multiple document buckets: blank, 10, 30, 64, 96 and >96 text lines; 768² and higher-resolution tiled pages; documents with/without tables.
  5. Measure peak RSS, inference parameter bytes, mean selected OCR lines, bucket counts, query count, tile count and all failure/rejection flags.
  6. Compare v3, v4 transformer-sparse, and v4 Conv1D with equivalent workload/corpus, not cherry-picked images.

Performance-oriented implementation rules

  • Avoid per-pixel CPU↔GPU transfers and Python loops in the inference hot path; v3's CPU conversion of all sorted candidates is a specific optimization target.
  • Batch grid sampling and recognition by sequence-length bucket; avoid materializing large unused padded tensors.
  • Cache immutable positional grids and token tables where safe; do not cache shape-dependent values incorrectly.
  • Instrument each stage before introducing more aggressive reparameterization or custom kernels.

A4 — Deep-Dive on Cross-Finding Blockers & v3.1 Architectural Remedies

Blocker A: Collide-Then-Suppress Heatmap Paradox in v3

Consider a TABLE and its central TABLE_CELL both centered at (0.5, 0.5) on a 16×16 grid. In v3's single-channel render_gt_heatmap, Box 0 snaps to (8, 8) and Box 1 is displaced to the nearest free cell (7, 7)—which sits at Chebyshev distance 1 (max(|8-7|, |8-7|) = 1). Because v3's select_non_duplicate_peaks unconditionally suppresses all neighbors with Chebyshev distance ≤ 1, even an oracle predictor outputting heat_probs == target_hm suffers a guaranteed false negative on Box 1.

v3.1 Fix: node_heatmap outputs C = 3 hierarchy channels (Tier 0: Containers TABLE/HEADER/FOOTER; Tier 1: Sub-regions TABLE_CELL/KEY/VALUE/LIST_ITEM; Tier 2: Text Lines) added with a learned tier_embed (only +578 params). Within each tier, Chebyshev suppression only suppresses flat plateau ties (|p_c - p_n| ≤ 1e-4) or weak shoulders (p_n < 0.5).

Blocker B: 9.15B MACs Unfiltered OCR Sequence Core

At K = 96, L = 160, D = 160, each DualModeSeqBlock(mode="ocr") performs 12.29M MACs for ocr_dw1d, 1,572.86M MACs for QKV/Out projections, 786.43M MACs for attention matrices, and 1,572.86M MACs for the FFN = 3.944B MACs per block (7.889B MACs across 2 blocks), plus 1.258B MACs in char_ctc_head = 9.147B MACs (18.29 GFLOPs).

v3.1 Fix: Because proposal_mask and role_logits are computed before the OCR branch, v3.1 indexes sample_oriented_strips and the OCR Transformer only on active text-bearing proposals (ocr_mask), cutting average inference MACs by 65–85% with zero parameter changes.

class CharTokenizer512:
    """
    Deterministic 512-class Unicode Character Vocabulary for CTC.
    - Index 0       : <BLANK> (strictly reserved for CTC blank)
    - Index 1       : <UNK>
    - Index 2..96   : Printable ASCII (U+0020..U+007E, 95 chars)
    - Index 97..224 : Full Khmer Unicode Block (U+1780..U+17FF, 128 chars)
    - Index 225..256: Khmer Symbols Block (U+19E0..U+19FF, 32 chars)
    - Index 257..511: Latin-1 Supplement, General Punctuation & Currency (255 chars)
    """

    def __init__(self):
        self.id_to_char: List[str] = ["<BLANK>", "<UNK>"]
        for cp in range(0x0020, 0x007F):
            self.id_to_char.append(chr(cp))
        for cp in range(0x1780, 0x1800):
            self.id_to_char.append(chr(cp))
        for cp in range(0x19E0, 0x1A00):
            self.id_to_char.append(chr(cp))
        for cp in range(0x00A0, 0x0160):
            if len(self.id_to_char) < 512:
                self.id_to_char.append(chr(cp))
        for cp in range(0x2000, 0x2070):
            if len(self.id_to_char) < 512:
                self.id_to_char.append(chr(cp))
        assert len(self.id_to_char) == 512
        self.char_to_id: Dict[str, int] = {
            ch: idx for idx, ch in enumerate(self.id_to_char) if idx >= 2
        }
        self.blank_id = 0
        self.unk_id = 1

    def encode(self, text: str) -> List[int]:
        """Maps each Unicode character to a strictly positive class ID in [1, 511]."""
        return [self.char_to_id.get(ch, self.unk_id) for ch in text]

    @staticmethod
    def min_ctc_frames(token_ids: List[int]) -> int:
        """
        Computes the exact minimum number of CTC frames required to align `token_ids`:
        len(token_ids) + number of adjacent duplicate token pairs.
        """
        if not token_ids:
            return 0
        repeats = sum(
            1 for i in range(1, len(token_ids)) if token_ids[i] == token_ids[i - 1]
        )
        return len(token_ids) + repeats

    @classmethod
    def truncate_to_ctc_budget(
        cls, token_ids: List[int], max_frames: int
    ) -> List[int]:
        """Truncates a token sequence to the longest prefix that fits within `max_frames` CTC steps."""
        out: List[int] = []
        used = 0
        for tid in token_ids:
            step = 2 if (out and out[-1] == tid) else 1
            if used + step > max_frames:
                break
            out.append(tid)
            used += step
        return out

    def decode_ctc(self, logits_1d: torch.Tensor) -> str:
        """Greedy CTC collapse over (L, 512) frame logits."""
        pred_ids = logits_1d.argmax(dim=-1).tolist()
        out_chars: List[str] = []
        prev = self.blank_id
        for idx in pred_ids:
            if idx != self.blank_id and idx != prev:
                if idx != self.unk_id:
                    out_chars.append(self.id_to_char[idx])
            prev = idx
        return "".join(out_chars)

class HungarianMatcher:
    """
    Exact minimum-weight bipartite assignment (Jonker-Volgenant / Kuhn-Munkres)
    supporting arbitrary rectangular cost matrices (M=0, M < K, M == K, M > K)
    with zero external dependencies beyond PyTorch.
    """

    @staticmethod
    @torch.no_grad()
    def assign(cost_matrix: torch.Tensor) -> Tuple[torch.Tensor, torch.Tensor]:
        device = cost_matrix.device
        M, K = cost_matrix.shape
        if M == 0 or K == 0:
            empty = torch.zeros(0, dtype=torch.long, device=device)
            return empty, empty

        cost_cpu = cost_matrix.detach().float().cpu().tolist()
        transposed = False
        if M > K:
            cost_cpu = [[cost_cpu[r][c] for r in range(M)] for c in range(K)]
            n, m = K, M
            transposed = True
        else:
            n, m = M, K

        u = [0.0] * (n + 1)
        v = [0.0] * (m + 1)
        p = [0] * (m + 1)
        way = [0] * (m + 1)

        for i in range(1, n + 1):
            p[0] = i
            j0 = 0
            minv = [float("inf")] * (m + 1)
            used = [False] * (m + 1)
            while True:
                used[j0] = True
                i0 = p[j0]
                delta = float("inf")
                j1 = 0
                row_i0 = cost_cpu[i0 - 1]
                u_i0 = u[i0]
                for j in range(1, m + 1):
                    if not used[j]:
                        cur = row_i0[j - 1] - u_i0 - v[j]
                        if cur < minv[j]:
                            minv[j] = cur
                            way[j] = j0
                        if minv[j] < delta:
                            delta = minv[j]
                            j1 = j
                for j in range(m + 1):
                    if used[j]:
                        u[p[j]] += delta
                        v[j] -= delta
                    else:
                        minv[j] -= delta
                j0 = j1
                if p[j0] == 0:
                    break
            while True:
                j1 = way[j0]
                p[j0] = p[j1]
                j0 = j1
                if j0 == 0:
                    break

        pairs: List[Tuple[int, int]] = []
        for j in range(1, m + 1):
            if p[j] > 0:
                if transposed:
                    pairs.append((j - 1, p[j] - 1))
                else:
                    pairs.append((p[j] - 1, j - 1))
        pairs.sort(key=lambda rc: rc[0])
        rows = torch.tensor([r for r, _ in pairs], dtype=torch.long, device=device)
        cols = torch.tensor([c for _, c in pairs], dtype=torch.long, device=device)
        return rows, cols

    @classmethod
    @torch.no_grad()
    def match_proposals(
        cls,
        anchor_xy: torch.Tensor,      # (K, 2)
        pred_boxes: torch.Tensor,     # (K, 6)
        node_scores: torch.Tensor,    # (K,)
        proposal_mask: torch.Tensor,  # (K,) bool
        gt_boxes: torch.Tensor,       # (M, 6)
        gt_roles: Optional[torch.Tensor] = None,     # (M,) optional role id
        proposal_tiers: Optional[torch.Tensor] = None,  # (K,) optional tier id
    ) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        Matches M ground-truth boxes to valid non-duplicate proposals in K.
        Handles M = 0, M <= K_valid, and M > K_valid cleanly without exceptions.
        """
        device = anchor_xy.device
        M = gt_boxes.shape[0]
        valid_k = torch.where(proposal_mask)[0]
        if M == 0 or valid_k.numel() == 0:
            empty = torch.zeros(0, dtype=torch.long, device=device)
            return empty, empty

        anc_v = anchor_xy[valid_k]
        box_v = pred_boxes[valid_k]
        scr_v = node_scores[valid_k]

        dist_xy = torch.cdist(gt_boxes[:, :2].float(), anc_v.float(), p=2)
        dist_box = torch.cdist(gt_boxes[:, :4].float(), box_v[:, :4].float(), p=1)
        cost = 2.0 * dist_xy + 1.0 * dist_box - 0.25 * scr_v.float().unsqueeze(0)

        if gt_roles is not None and proposal_tiers is not None:
            gt_tier = PrismOCRv3.role_to_tier_tensor(gt_roles)
            prop_tier_v = proposal_tiers[valid_k]
            tier_mismatch = (gt_tier.unsqueeze(1) != prop_tier_v.unsqueeze(0)).float()
            cost = cost + 0.5 * tier_mismatch

        m_idx, kv_idx = cls.assign(cost)
        return m_idx, valid_k[kv_idx]

class AnisotropicRepDW(nn.Module):
    def __init__(self, channels: int):
        super().__init__()
        self.c = channels
        self.dw_3x3 = nn.Conv2d(
            channels, channels, (3, 3), 1, (1, 1), groups=channels, bias=False
        )
        self.bn_3x3 = nn.BatchNorm2d(channels)
        self.dw_1x7 = nn.Conv2d(
            channels, channels, (1, 7), 1, (0, 3), groups=channels, bias=False
        )
        self.bn_1x7 = nn.BatchNorm2d(channels)
        self.dw_3x1 = nn.Conv2d(
            channels, channels, (3, 1), 1, (1, 0), groups=channels, bias=False
        )
        self.bn_3x1 = nn.BatchNorm2d(channels)
        self.bn_id = nn.BatchNorm2d(channels)
        self.fused_conv: Optional[nn.Conv2d] = None

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        if self.fused_conv is not None:
            return self.fused_conv(x)
        return (
            self.bn_3x3(self.dw_3x3(x))
            + self.bn_1x7(self.dw_1x7(x))
            + self.bn_3x1(self.dw_3x1(x))
            + self.bn_id(x)
        )

    @torch.no_grad()
    def fuse_for_inference(self) -> None:
        if self.fused_conv is not None:
            return
        device = self.dw_3x3.weight.device
        orig_dtype = self.dw_3x3.weight.dtype
        fused_k = torch.zeros((self.c, 1, 3, 7), device=device, dtype=torch.float32)
        fused_b = torch.zeros(self.c, device=device, dtype=torch.float32)

        def _fuse_bn(conv_w: torch.Tensor, bn: nn.BatchNorm2d):
            w_fp32 = conv_w.float()
            std = (bn.running_var.float() + bn.eps).sqrt()
            scale = (bn.weight.float() / std).reshape(-1, 1, 1, 1)
            bias = bn.bias.float() - bn.running_mean.float() * bn.weight.float() / std
            return w_fp32 * scale, bias

        w33, b33 = _fuse_bn(self.dw_3x3.weight, self.bn_3x3)
        fused_k[:, :, :, 2:5] += w33
        fused_b += b33

        w17, b17 = _fuse_bn(self.dw_1x7.weight, self.bn_1x7)
        fused_k[:, :, 1:2, :] += w17
        fused_b += b17

        w31, b31 = _fuse_bn(self.dw_3x1.weight, self.bn_3x1)
        fused_k[:, :, :, 3:4] += w31
        fused_b += b31

        id_w = torch.zeros((self.c, 1, 3, 7), device=device, dtype=torch.float32)
        id_w[:, 0, 1, 3] = 1.0
        wid, bid = _fuse_bn(id_w, self.bn_id)
        fused_k += wid
        fused_b += bid

        self.fused_conv = nn.Conv2d(
            self.c, self.c, (3, 7), 1, (1, 3), groups=self.c, bias=True
        ).to(device=device, dtype=orig_dtype)
        self.fused_conv.weight.copy_(fused_k.to(orig_dtype))
        self.fused_conv.bias.copy_(fused_b.to(orig_dtype))
        del (
            self.dw_3x3,
            self.bn_3x3,
            self.dw_1x7,
            self.bn_1x7,
            self.dw_3x1,
            self.bn_3x1,
            self.bn_id,
        )


class RepBlock(nn.Module):
    def __init__(self, channels: int, exp_ratio: float = 2.5):
        super().__init__()
        hidden = int(channels * exp_ratio)
        self.dw = AnisotropicRepDW(channels)
        self.pw1 = nn.Conv2d(channels, hidden, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(hidden)
        self.act = nn.SiLU(inplace=True)
        self.pw2 = nn.Conv2d(hidden, channels, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        return x + self.bn2(self.pw2(self.act(self.bn1(self.pw1(self.dw(x))))))


class DualModeSeqBlock(nn.Module):
    def __init__(self, d_model: int = 160, nhead: int = 5):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, nhead, batch_first=True)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_model * 2),
            nn.SiLU(inplace=True),
            nn.Linear(d_model * 2, d_model),
        )
        self.ocr_dw1d = nn.Conv1d(
            d_model, d_model, kernel_size=5, padding=2, groups=d_model, bias=False
        )
        self.ocr_bn1d = nn.BatchNorm1d(d_model)
        self.norm1_struct = nn.LayerNorm(d_model)
        self.norm2_struct = nn.LayerNorm(d_model)
        self.norm1_ocr = nn.LayerNorm(d_model)
        self.norm2_ocr = nn.LayerNorm(d_model)

    def forward(
        self,
        x: torch.Tensor,
        mode: str = "struct",
        key_padding_mask: Optional[torch.Tensor] = None,
    ) -> torch.Tensor:
        if x.shape[0] == 0:
            return x
        if mode == "ocr":
            x = x + F.silu(
                self.ocr_bn1d(self.ocr_dw1d(x.transpose(1, 2)))
            ).transpose(1, 2)
            n1, n2 = self.norm1_ocr, self.norm2_ocr
        else:
            n1, n2 = self.norm1_struct, self.norm2_struct
        h = n1(x)
        # Ensure at least one valid token per batch row to avoid NaN in softmax
        if key_padding_mask is not None:
            safe_mask = key_padding_mask.clone()
            all_masked = safe_mask.all(dim=-1)
            if all_masked.any():
                safe_mask[all_masked, 0] = False
        else:
            safe_mask = None
        attn_out, _ = self.attn(
            h, h, h, key_padding_mask=safe_mask, need_weights=False
        )
        x = x + attn_out
        return x + self.ffn(n2(x))

# 4. Complete Cycle-Safe Reading-Order, Key-Value & Span-Preserving Table Decoder

class DocumentGraphDecoder:
    @staticmethod
    def traverse_reading_order(
        active_ids: List[int],
        boxes: torch.Tensor,       # (K, 6)
        next_probs: torch.Tensor,  # (K, K) softmax probabilities on Channel 0
    ) -> List[int]:
        """
        Builds a maximum-confidence reading-order pointer graph, breaks any directed
        cycles at their weakest confidence link, and runs Kahn's topological sort
        with a 2D geometric priority queue (row_band, cx).
        """
        if not active_ids:
            return []

        def _geom_key(idx: int) -> Tuple[int, float, int]:
            cx, cy, _, h = [float(boxes[idx, k].item()) for k in range(4)]
            return (int(cy / max(h * 0.75, 0.02)), cx, idx)

        out_edge: Dict[int, Tuple[int, float]] = {}
        for u in active_ids:
            candidates = [v for v in active_ids if v != u]
            if not candidates:
                continue
            best_v = max(candidates, key=lambda v: float(next_probs[u, v].item()))
            p_uv = float(next_probs[u, best_v].item())
            p_uu = float(next_probs[u, u].item())
            if p_uv > p_uu and p_uv >= 0.25:
                out_edge[u] = (best_v, p_uv)

        # Break any cycles at the minimum-probability edge in the cycle
        state = {u: 0 for u in active_ids}
        for u in active_ids:
            if state[u] != 0:
                continue
            path: List[int] = []
            curr: Optional[int] = u
            while curr is not None and state[curr] == 0:
                state[curr] = 1
                path.append(curr)
                curr = out_edge[curr][0] if curr in out_edge else None
            if curr is not None and state[curr] == 1:
                cycle_nodes = path[path.index(curr) :]
                weakest_u = min(cycle_nodes, key=lambda n: out_edge[n][1])
                del out_edge[weakest_u]
            for n in path:
                state[n] = 2

        in_deg = {u: 0 for u in active_ids}
        adj: Dict[int, List[int]] = {u: [] for u in active_ids}
        for u, (v, _) in out_edge.items():
            adj[u].append(v)
            in_deg[v] += 1

        heap = [(_geom_key(u), u) for u in active_ids if in_deg[u] == 0]
        heapq.heapify(heap)
        ordered: List[int] = []
        while heap:
            _, u = heapq.heappop(heap)
            ordered.append(u)
            for v in adj[u]:
                in_deg[v] -= 1
                if in_deg[v] == 0:
                    heapq.heappush(heap, (_geom_key(v), v))
        return ordered

    @staticmethod
    def reconstruct_tables(
        nodes_dict: Dict[int, Dict[str, Any]],
        parent_probs: torch.Tensor,
        right_probs: torch.Tensor,
    ) -> List[Dict[str, Any]]:

        Uses both geometric intervals AND Channel 3 (right_probs) horizontal adjacency
        pointers to recover (row, col, rowspan, colspan) and render span-preserving HTML & Markdown.
        """
        table_nodes = [i for i, n in nodes_dict.items() if n["role"] == "TABLE"]
        cell_nodes = [i for i, n in nodes_dict.items() if n["role"] == "TABLE_CELL"]
        if not cell_nodes:
            return []

        if not table_nodes:
            table_groups = {-1: cell_nodes}
        else:
            table_groups = {t_id: [] for t_id in table_nodes}
            for c_id in cell_nodes:
                best_t = max(
                    table_nodes,
                    key=lambda t_id: float(parent_probs[c_id, t_id].item()),
                )
                table_groups[best_t].append(c_id)

        reconstructed_tables = []
        for t_id, cells in table_groups.items():
            if not cells:
                continue
            intervals: Dict[int, List[float]] = {}
            for c_id in cells:
                cx, cy, w, h = nodes_dict[c_id]["box"][:4]
                intervals[c_id] = [
                    cx - w / 2.0,
                    cy - h / 2.0,
                    cx + w / 2.0,
                    cy + h / 2.0,
                    cx,
                    cy,

            # Apply right_probs (Channel 3) to separate horizontally linked cells
            for u in cells:
                others = [v for v in cells if v != u]
                if not others:
                    continue
                best_v = max(others, key=lambda v: float(right_probs[u, v].item()))
                if float(right_probs[u, best_v].item()) > max(
                    float(right_probs[u, u].item()), 0.35
                ):
                    if (
                        intervals[u][4] < intervals[best_v][4]
                        and intervals[u][2] > intervals[best_v][0]
                    ):
                        mid_x = 0.5 * (intervals[u][4] + intervals[best_v][4])
                        intervals[u][2] = min(intervals[u][2], mid_x - 1e-3)
                        intervals[best_v][0] = max(intervals[best_v][0], mid_x + 1e-3)

                matched = False
                for r_idx, (ry1, ry2) in enumerate(row_tracks):
                    overlap = min(y2, ry2) - max(y1, ry1)
                    if overlap / max(min(h, ry2 - ry1), 1e-4) > 0.5:
                        if h <= (ry2 - ry1) * 1.35:
                            row_tracks[r_idx] = (min(y1, ry1), max(y2, ry2))
                        matched = True
                        break
                if not matched and h <= 1.6 * min_cell_h:
                    row_tracks.append((y1, y2))
            if not row_tracks:
                row_tracks = [
                    (intervals[sorted_by_h[0]][1], intervals[sorted_by_h[0]][3])
                ]
            row_tracks.sort(key=lambda r: 0.5 * (r[0] + r[1]))

            # 2. Cluster column tracks (smallest-width cells first)
            sorted_by_w = sorted(cells, key=lambda i: (intervals[i][6], intervals[i][4]))
            min_cell_w = min(intervals[k][6] for k in cells)
            col_tracks: List[Tuple[float, float]] = []
            for c_id in sorted_by_w:
                x1, _, x2, _, _, _, w, _ = intervals[c_id]
                matched = False
                for c_idx, (cx1, cx2) in enumerate(col_tracks):
                    overlap = min(x2, cx2) - max(x1, cx1)
                    if overlap / max(min(w, cx2 - cx1), 1e-4) > 0.45:
                        if w <= (cx2 - cx1) * 1.35:
                            col_tracks[c_idx] = (min(x1, cx1), max(x2, cx2))
                        matched = True
                        break
                if not matched and w <= 1.6 * min_cell_w:
                    col_tracks.append((x1, x2))
            if not col_tracks:
                col_tracks = [
                    (intervals[sorted_by_w[0]][0], intervals[sorted_by_w[0]][2])
                ]
            col_tracks.sort(key=lambda c: 0.5 * (c[0] + c[1]))

            num_rows, num_cols = len(row_tracks), len(col_tracks)
            structured_cells = []
            occupied = [[False for _ in range(num_cols)] for _ in range(num_rows)]
            cell_by_origin: Dict[Tuple[int, int], Dict[str, Any]] = {}

            for c_id in cells:
                x1, y1, x2, y2, cx, cy, _, _ = intervals[c_id]
                spanned_rows = [
                    r
                    for r, (ry1, ry2) in enumerate(row_tracks)
                    if (min(y2, ry2) - max(y1, ry1)) / max(ry2 - ry1, 1e-4) > 0.35
                ] or [
                    min(
                        range(num_rows),
                        key=lambda r: abs(
                            cy - 0.5 * (row_tracks[r][0] + row_tracks[r][1])
                        ),
                    )
                ]

                spanned_cols = [
                    c
                    for c, (cx1, cx2) in enumerate(col_tracks)
                    if (min(x2, cx2) - max(x1, cx1)) / max(cx2 - cx1, 1e-4) > 0.35
                ] or [
                    min(
                        range(num_cols),
                        key=lambda c: abs(
                            cx - 0.5 * (col_tracks[c][0] + col_tracks[c][1])
                        ),
                    )
                ]

                r_start, r_span = spanned_rows[0], len(spanned_rows)
                c_start, c_span = spanned_cols[0], len(spanned_cols)
                entry = {
                    "node_id": c_id,
                    "row": r_start,
                    "col": c_start,
                    "rowspan": r_span,
                    "colspan": c_span,
                    "text": nodes_dict[c_id]["text"],
                }
                structured_cells.append(entry)
                cell_by_origin[(r_start, c_start)] = entry
                for rr in range(r_start, min(num_rows, r_start + r_span)):
                    for cc in range(c_start, min(num_cols, c_start + c_span)):
                        if not (rr == r_start and cc == c_start):
                            occupied[rr][cc] = True

            # Span-Preserving HTML Table (never duplicates spanned cells)
            html_lines = ["<table>"]
            for r in range(num_rows):
                tag = "th" if r == 0 else "td"
                html_lines.append("  <tr>")
                for c in range(num_cols):
                    if occupied[r][c]:
                        continue
                    cell = cell_by_origin.get((r, c))
                    if cell is not None:
                        attrs = ""
                        if cell["rowspan"] > 1:
                            attrs += f' rowspan="{cell["rowspan"]}"'
                        if cell["colspan"] > 1:
                            attrs += f' colspan="{cell["colspan"]}"'
                        html_lines.append(f"    <{tag}{attrs}>{cell['text']}</{tag}>")
                    else:
                        html_lines.append(f"    <{tag}></{tag}>")
                html_lines.append("  </tr>")
            html_lines.append("</table>")

            # Clean Markdown Table (without repeating text inside covered cells)
            md_lines = []
            for r in range(num_rows):
                row_vals = []
                for c in range(num_cols):
                    cell = cell_by_origin.get((r, c))
                    if cell is not None:
                        span_tag = (
                            f" [{cell['rowspan']}x{cell['colspan']}]"
                            if (cell["rowspan"] > 1 or cell["colspan"] > 1)
                            else ""
                        )
                        row_vals.append(f"{cell['text']}{span_tag}")
                    else:
                        row_vals.append("")
                md_lines.append("| " + " | ".join(row_vals) + " |")
                if r == 0:
                    md_lines.append("|" + "|".join(["---"] * num_cols) + "|")

            reconstructed_tables.append(
                {
                    "table_node_id": t_id,
                    "num_rows": num_rows,
                    "num_cols": num_cols,
                    "cells": sorted(
                        structured_cells, key=lambda c: (c["row"], c["col"])
                    ),
                    "html": "\n".join(html_lines),
                    "markdown": "\n".join(md_lines),
                }
            )
        return reconstructed_tables

class PrismOCRv3(nn.Module):
    ROLES = [
        "PAD",         # 0
        "TITLE",       # 1 (Tier 2: Text line)
        "H1",          # 2 (Tier 2: Text line)
        "H2",          # 3 (Tier 2: Text line)
        "PARA_LINE",   # 4 (Tier 2: Text line)
        "LIST_ITEM",   # 5 (Tier 1: Sub-region / cell / item)
        "TABLE",       # 6 (Tier 0: Layout container)
        "TABLE_CELL",  # 7 (Tier 1: Sub-region / cell / item)
        "KEY",         # 8 (Tier 1: Sub-region / cell / item)
        "VALUE",       # 9 (Tier 1: Sub-region / cell / item)
        "FORMULA",     # 10 (Tier 2: Text line)
        "CAPTION",     # 11 (Tier 2: Text line)
        "HEADER",      # 12 (Tier 0: Layout container)
        "FOOTER",      # 13 (Tier 0: Layout container)
    ]
    CONTAINER_ROLES = {0, 6}  # PAD and TABLE do not carry line-level CTC glyph sequences

    @staticmethod
    def role_to_tier(role_id: int) -> int:
        if role_id in (6, 12, 13):
            return 0  # Tier 0: Containers (TABLE, HEADER, FOOTER)
        if role_id in (5, 7, 8, 9):
            return 1  # Tier 1: Cells & KV / List spans (LIST_ITEM, TABLE_CELL, KEY, VALUE)
        return 2      # Tier 2: Text lines (TITLE, H1, H2, PARA_LINE, FORMULA, CAPTION)

    @classmethod
    def role_to_tier_tensor(cls, roles: torch.Tensor) -> torch.Tensor:
        tiers = torch.full_like(roles, 2)
        tiers[(roles == 6) | (roles == 12) | (roles == 13)] = 0
        tiers[(roles == 5) | (roles == 7) | (roles == 8) | (roles == 9)] = 1
        return tiers

    def __init__(
        self,
        d_model: int = 160,
        max_nodes: int = 96,
        strip_len: int = 160,
        pool_h: int = 5,
        num_roles: int = 14,
        num_tiers: int = 3,
        char_vocab: int = 512,
    ):
        super().__init__()
        self.d_model = d_model
        self.max_nodes = max_nodes
        self.strip_len = strip_len
        self.pool_h = pool_h
        self.num_tiers = num_tiers
        self.tokenizer = CharTokenizer512()

        # 1. Shared Multi-Scale Anisotropic Backbone
        self.stem = nn.Sequential(
            nn.Conv2d(3, 32, 3, 2, 1, bias=False),
            nn.BatchNorm2d(32),
            nn.SiLU(inplace=True),
            nn.Conv2d(32, 64, 3, 2, 1, bias=False),
            nn.BatchNorm2d(64),
            nn.SiLU(inplace=True),
        )  # H/4
        self.stage4 = nn.Sequential(RepBlock(64, 2.0), RepBlock(64, 2.0))
        self.down8 = nn.Sequential(
            nn.Conv2d(64, 112, 3, 2, 1, bias=False),
            nn.BatchNorm2d(112),
            nn.SiLU(inplace=True),
        )  # H/8
        self.stage8 = nn.Sequential(
            RepBlock(112, 2.5), RepBlock(112, 2.5), RepBlock(112, 2.5)
        )
        self.down16 = nn.Sequential(
            nn.Conv2d(112, d_model, 3, 2, 1, bias=False),
            nn.BatchNorm2d(d_model),
            nn.SiLU(inplace=True),
        )  # H/16
        self.stage16 = nn.Sequential(
            RepBlock(d_model, 2.5), RepBlock(d_model, 2.5), RepBlock(d_model, 2.5)
        )
        self.cpe16 = nn.Conv2d(d_model, d_model, 3, 1, 1, groups=d_model)

        # 2. Hierarchy-Aware 3-Tier Peak Proposal Head (Containers, Cells/Spans, Text Lines)
        self.node_heatmap = nn.Conv2d(d_model, num_tiers, 1)
        self.tier_embed = nn.Embedding(num_tiers, d_model)
        self.pos_enc = nn.Sequential(
            nn.Linear(2, d_model), nn.SiLU(), nn.Linear(d_model, d_model)
        )

        # 3. Weight-Shared Dual-Mode Transformer
        self.shared_seq_blocks = nn.ModuleList(
            [DualModeSeqBlock(d_model, nhead=5) for _ in range(2)]
        )

        # 4. Structure & 4-Channel Relational Adjacency Heads
        self.role_head = nn.Linear(d_model, num_roles)
        self.box_head = nn.Sequential(
            nn.Linear(d_model, d_model), nn.SiLU(), nn.Linear(d_model, 6)
        )
        self.rel_q = nn.Linear(d_model, 4 * 48)
        self.rel_k = nn.Linear(d_model, 4 * 48)

        # 5. High-Res Glyph Neck + Multi-Row Vertical Collapse + 512-Class Character CTC
        self.lat4 = nn.Conv2d(64, d_model, 1, bias=False)
        self.lat8 = nn.Conv2d(112, d_model, 1, bias=False)
        self.vert_collapse = nn.Conv2d(
            d_model, d_model, kernel_size=(pool_h, 1), groups=d_model, bias=True
        )
        self.char_ctc_head = nn.Linear(d_model, char_vocab)

    def sample_oriented_strips(
        self,
        f_glyph: torch.Tensor,
        boxes: torch.Tensor,
        node_embeds: torch.Tensor,
        override_strip_len: Optional[int] = None,
    ) -> torch.Tensor:
        """Samples a 2D (P_h=5 x L) oriented feature grid per box and collapses P_h -> 1."""
        B, D, _, _ = f_glyph.shape
        K = boxes.shape[1]
        P_h = self.pool_h
        L = override_strip_len if override_strip_len is not None else self.strip_len
        if K == 0:
            return torch.zeros((0, L, D), device=f_glyph.device, dtype=f_glyph.dtype)

        cx = boxes[..., 0:1] * 2.0 - 1.0
        cy = boxes[..., 1:2] * 2.0 - 1.0
        w, h = boxes[..., 2:3], boxes[..., 3:4]
        sin_t, cos_t = boxes[..., 4:5], boxes[..., 5:6]
        norm = torch.sqrt(sin_t**2 + cos_t**2 + 1e-6)
        sin_t, cos_t = sin_t / norm, cos_t / norm

        theta = torch.zeros(
            (B, K, 2, 3), device=f_glyph.device, dtype=f_glyph.dtype
        )
        theta[:, :, 0, 0] = (cos_t * w).squeeze(-1)
        theta[:, :, 0, 1] = (-sin_t * h).squeeze(-1)
        theta[:, :, 0, 2] = cx.squeeze(-1)
        theta[:, :, 1, 0] = (sin_t * w).squeeze(-1)
        theta[:, :, 1, 1] = (cos_t * h).squeeze(-1)
        theta[:, :, 1, 2] = cy.squeeze(-1)

        ys_1d = torch.linspace(
            -1.0, 1.0, P_h, device=f_glyph.device, dtype=f_glyph.dtype
        )
        xs_1d = torch.linspace(
            -1.0, 1.0, L, device=f_glyph.device, dtype=f_glyph.dtype
        )
        grid_y, grid_x = torch.meshgrid(ys_1d, xs_1d, indexing="ij")
        homog = torch.stack(
            [grid_x, grid_y, torch.ones_like(grid_x)], dim=-1
        ).reshape(1, 1, P_h * L, 3)
        grid = torch.matmul(homog.expand(B, K, -1, -1), theta.transpose(-1, -2))

        sampled = F.grid_sample(
            f_glyph,
            grid,
            mode="bilinear",
            padding_mode="zeros",
            align_corners=False,
        )
        patches = sampled.permute(0, 2, 1, 3).reshape(B * K, D, P_h, L)
        collapsed = F.silu(self.vert_collapse(patches)).squeeze(2).transpose(1, 2)
        return collapsed + node_embeds.reshape(B * K, 1, D)

    def select_non_duplicate_peaks(
        self, heat_logits: torch.Tensor
    ) -> Tuple[torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor, torch.Tensor]:
        """
        Hierarchy-Aware Plateau-Safe Peak Selection:
        Evaluates across C=3 hierarchy tiers (Tier 0: Containers, Tier 1: Cells/KV,
        Tier 2: Text Lines). Within each tier, suppresses 3x3 Chebyshev neighbors ONLY
        when they belong to a flat plateau (|p_center - p_neighbor| <= 1e-4) or are
        strictly lower than a local maximum, preserving distinct adjacent peaks while
        still guaranteeing stride-2 spacing on flat plateaus.
        """
        B, C, H16, W16 = heat_logits.shape
        device = heat_logits.device
        heat_probs = heat_logits.sigmoid()
        K = min(self.max_nodes, C * H16 * W16)

        yy = torch.arange(H16, device=device).view(1, H16, 1)
        xx = torch.arange(W16, device=device).view(1, 1, W16)
        cc_idx = torch.arange(C, device=device).view(C, 1, 1)
        tie_break = (
            ((yy % 2 == 0) & (xx % 2 == 0)).float() * 1e-6
            + (cc_idx * H16 * W16 + yy * W16 + xx).float() * 1e-9
        )

        topk_spatial_list: List[torch.Tensor] = []
        topk_tier_list: List[torch.Tensor] = []
        mask_list: List[torch.Tensor] = []
        prob_list: List[torch.Tensor] = []

        with torch.no_grad():
            probs_cpu = heat_probs.detach().float().cpu().tolist()
            scores_all = (heat_probs.detach().float() + tie_break).flatten(1)
            sorted_orders = (
                torch.argsort(scores_all, dim=1, descending=True).cpu().tolist()
            )

            for b in range(B):
                suppressed = [
                    [[False] * W16 for _ in range(H16)] for _ in range(C)
                ]
                sel_spatial: List[int] = []
                sel_tier: List[int] = []
                sel_flat: List[int] = []

                for flat_i in sorted_orders[b]:
                    tier, rem = divmod(flat_i, H16 * W16)
                    r, c = divmod(rem, W16)
                    if not suppressed[tier][r][c]:
                        p_center = probs_cpu[b][tier][r][c]
                        sel_spatial.append(rem)
                        sel_tier.append(tier)
                        sel_flat.append(flat_i)
                        suppressed[tier][r][c] = True

                        r0, r1 = max(0, r - 1), min(H16, r + 2)
                        c0, c1 = max(0, c - 1), min(W16, c + 2)
                        for rr in range(r0, r1):
                            for cc in range(c0, c1):
                                if rr == r and cc == c:
                                    continue
                                p_nb = probs_cpu[b][tier][rr][cc]
                                # Suppress plateau ties or weak shoulders, but preserve
                                # distinct high-confidence adjacent peaks (p_nb >= 0.5)
                                if abs(p_center - p_nb) <= 1e-4 or p_nb < 0.5:
                                    suppressed[tier][rr][cc] = True
                        if len(sel_spatial) == K:
                            break

                n_sel = len(sel_spatial)
                pad_len = K - n_sel
                topk_spatial_list.append(
                    torch.tensor(
                        sel_spatial + [0] * pad_len, dtype=torch.long, device=device
                    )
                )
                topk_tier_list.append(
                    torch.tensor(
                        sel_tier + [0] * pad_len, dtype=torch.long, device=device
                    )
                )
                mask_list.append(
                    torch.tensor(
                        [True] * n_sel + [False] * pad_len,
                        dtype=torch.bool,
                        device=device,
                    )
                )
                flat_tensor = torch.tensor(
                    sel_flat + [0] * pad_len, dtype=torch.long, device=device
                )
                prob_list.append(flat_tensor)

        topk_idx = torch.stack(topk_spatial_list, dim=0)
        proposal_tiers = torch.stack(topk_tier_list, dim=0)
        proposal_mask = torch.stack(mask_list, dim=0)
        flat_gather_idx = torch.stack(prob_list, dim=0)
        true_probs = torch.gather(
            heat_probs.flatten(1), 1, flat_gather_idx
        ) * proposal_mask.to(heat_probs.dtype)
        return true_probs, topk_idx, proposal_tiers, proposal_mask, heat_probs

    def align_teacher_forced_boxes(
        self,
        pred_boxes: torch.Tensor,      # (B, K, 6)
        anchor_xy: torch.Tensor,       # (B, K, 2)
        node_scores: torch.Tensor,     # (B, K)
        proposal_mask: torch.Tensor,   # (B, K)
        proposal_tiers: torch.Tensor,  # (B, K)
        gt_boxes: Union[torch.Tensor, List[torch.Tensor]],
        teacher_force_ratio: float = 1.0,
    ) -> Tuple[torch.Tensor, torch.Tensor]:
        """
        Matches variable-count M_b ground-truth boxes to the K proposals via Hungarian
        assignment and replaces ONLY the matched proposal slots in a cloned (B, K, 6)
        tensor, returning both `aligned_boxes` and `matched_slot_mask` (B, K).
        """
        B, K, _ = pred_boxes.shape
        aligned = pred_boxes.clone()
        matched_slot_mask = torch.zeros(
            (B, K), dtype=torch.bool, device=pred_boxes.device
        )
        alpha = float(max(0.0, min(1.0, teacher_force_ratio)))

        for b in range(B):
            gt_b = gt_boxes[b].to(device=pred_boxes.device, dtype=pred_boxes.dtype)
            if gt_b.numel() == 0:
                continue
            m_idx, k_idx = HungarianMatcher.match_proposals(
                anchor_xy[b],
                pred_boxes[b],
                node_scores[b],
                proposal_mask[b],
                gt_b,
                proposal_tiers=proposal_tiers[b],
            )
            if m_idx.numel() > 0:
                matched_slot_mask[b, k_idx] = True
                if alpha > 0.0:
                    aligned[b, k_idx] = (
                        (1.0 - alpha) * pred_boxes[b, k_idx] + alpha * gt_b[m_idx]
                    )
        return aligned, matched_slot_mask

    def forward(
        self,
        x: torch.Tensor,
        gt_boxes: Optional[Union[torch.Tensor, List[torch.Tensor]]] = None,
        teacher_force_ratio: float = 1.0,
        override_strip_len: Optional[int] = None,
        score_thresh: float = 0.35,
        gate_ocr_by_active: bool = True,
    ) -> Dict[str, torch.Tensor]:
        B, _, _, _ = x.shape
        f4 = self.stage4(self.stem(x))
        f8 = self.stage8(self.down8(f4))
        f16 = self.stage16(self.down16(f8))
        f16 = f16 + self.cpe16(f16)

        _, D, H16, W16 = f16.shape
        heat_logits = self.node_heatmap(f16)
        topk_probs, topk_idx, proposal_tiers, proposal_mask, heat_probs = (
            self.select_non_duplicate_peaks(heat_logits)
        )
        K = topk_idx.shape[1]

        mem = f16.flatten(2).transpose(1, 2)
        nodes = torch.gather(mem, 1, topk_idx.unsqueeze(-1).expand(-1, -1, D))

        gy = (topk_idx // W16).to(x.dtype) / max(H16 - 1, 1)
        gx = (topk_idx % W16).to(x.dtype) / max(W16 - 1, 1)
        anchor_xy = torch.stack([gx, gy], dim=-1)

        nodes = (
            nodes * (0.5 + 0.5 * topk_probs.unsqueeze(-1))
            + self.pos_enc(anchor_xy)
            + self.tier_embed(proposal_tiers)
        )

        # Structural self-attention masks out unused/suppressed proposal slots
        pad_mask = ~proposal_mask
        for blk in self.shared_seq_blocks:
            nodes = blk(nodes, mode="struct", key_padding_mask=pad_mask)

        role_logits = self.role_head(nodes)
        raw_box = self.box_head(nodes)
        # Normalize (sin_t, cos_t) directly in `boxes` so box loss & sampler see unit vectors
        unit_orient = F.normalize(raw_box[..., 4:6], p=2, dim=-1, eps=1e-6)
        boxes = torch.cat(
            [
                (anchor_xy + 0.25 * torch.tanh(raw_box[..., :2])).clamp(0.0, 1.0),
                raw_box[..., 2:4].sigmoid().clamp(min=1e-3),
                unit_orient,
            ],
            dim=-1,
        )

        q_rel = self.rel_q(nodes).view(B, -1, 4, 48).permute(0, 2, 1, 3)
        k_rel = self.rel_k(nodes).view(B, -1, 4, 48).permute(0, 2, 3, 1)
        rel_logits = torch.matmul(q_rel, k_rel) / (48 ** 0.5)

        f_glyph = self.lat4(f4) + F.interpolate(
            self.lat8(f8), size=f4.shape[-2:], mode="bilinear", align_corners=False
        )
        if gt_boxes is not None:
            sample_boxes, matched_slot_mask = self.align_teacher_forced_boxes(
                boxes,
                anchor_xy,
                topk_probs,
                proposal_mask,
                proposal_tiers,
                gt_boxes,
                teacher_force_ratio,
            )
        else:
            sample_boxes = boxes
            matched_slot_mask = None

        L = override_strip_len if override_strip_len is not None else self.strip_len
        char_logits = torch.zeros(
            (B, K, L, 512), device=x.device, dtype=x.dtype
        )
        # Initialize blank logit high for non-decoded / masked slots
        char_logits[..., 0] = 10.0

        if gate_ocr_by_active:
            pred_roles = role_logits.argmax(dim=-1)
            is_text_role = (pred_roles != 0) & (pred_roles != 6)
            if self.training:
                # During training, decode all valid proposals (or matched slots)
                ocr_mask = proposal_mask if matched_slot_mask is None else (proposal_mask & matched_slot_mask)
            else:
                ocr_mask = proposal_mask & (topk_probs >= score_thresh) & is_text_role
        else:
            ocr_mask = torch.ones((B, K), dtype=torch.bool, device=x.device)

        # Sample and run OCR sequence blocks only on active text-bearing proposals
        for b in range(B):
            act_k = torch.where(ocr_mask[b])[0]
            if act_k.numel() == 0:
                continue
            strips_b = self.sample_oriented_strips(
                f_glyph[b : b + 1],
                sample_boxes[b : b + 1, act_k],
                nodes[b : b + 1, act_k],
                override_strip_len=L,
            )
            for blk in self.shared_seq_blocks:
                strips_b = blk(strips_b, mode="ocr")
            char_logits[b, act_k] = self.char_ctc_head(strips_b)

        return {
            "heat_logits": heat_logits,
            "heat_probs": heat_probs,
            "topk_idx": topk_idx,
            "proposal_tiers": proposal_tiers,
            "proposal_mask": proposal_mask,
            "ocr_active_mask": ocr_mask,
            "anchor_xy": anchor_xy,
            "node_scores": topk_probs,
            "role_logits": role_logits,
            "boxes": boxes,
            "sample_boxes": sample_boxes,
            "rel_logits": rel_logits,
            "char_logits": char_logits,
        }

    def fuse_for_inference(self) -> None:
        for m in self.modules():
            if isinstance(m, AnisotropicRepDW):
                m.fuse_for_inference()

    def extract_structured_document(
        self, outputs: Dict[str, torch.Tensor], score_thresh: float = 0.35
    ) -> Dict[str, Any]:
        scores = outputs["node_scores"][0]
        prop_mask = outputs["proposal_mask"][0]
        roles = outputs["role_logits"][0].argmax(dim=-1)
        boxes = outputs["boxes"][0]
        rel_probs = outputs["rel_logits"][0].softmax(dim=-1)
        rel_ids = rel_probs.argmax(dim=-1)
        char_logits = outputs["char_logits"][0]

        active_ids = [
            i
            for i in range(scores.shape[0])
            if bool(prop_mask[i].item())
            and scores[i].item() >= score_thresh
            and roles[i].item() != 0
        ]
        ordered_ids = DocumentGraphDecoder.traverse_reading_order(
            active_ids, boxes, rel_probs[0]
        )

        nodes_dict = {}
        for rank, i in enumerate(ordered_ids):
            role_name = self.ROLES[roles[i].item()]
            nodes_dict[i] = {
                "id": i,
                "reading_order": rank,
                "role": role_name,
                "box": [round(v, 4) for v in boxes[i].tolist()],
                "text": "" if role_name == "TABLE" else self.tokenizer.decode_ctc(char_logits[i]),
                "next_id": int(rel_ids[0, i].item()),
                "parent_id": int(rel_ids[1, i].item()),
                "kv_val_id": int(rel_ids[2, i].item()),
                "right_cell_id": int(rel_ids[3, i].item()),
            }

        # Validated Key->Value extraction: target must exist, not be a self-loop, and have role == "VALUE"
        kv_pairs = {}
        for i, n in nodes_dict.items():
            target = n["kv_val_id"]
            if (
                n["role"] == "KEY"
                and target != i
                and target in nodes_dict
                and nodes_dict[target]["role"] == "VALUE"
            ):
                kv_pairs[n["text"].strip(": ")] = nodes_dict[target]["text"]

        tables = DocumentGraphDecoder.reconstruct_tables(
            nodes_dict, rel_probs[1], rel_probs[3]
        )
        return {
            "reading_ordered_nodes": [nodes_dict[i] for i in ordered_ids],
            "key_value_extractions": kv_pairs,
            "tables": tables,
        }

# 6. Complete Target Assignment & Unified Loss Module (PrismOCRLoss)

class PrismOCRLoss(nn.Module):
    def __init__(
        self, tokenizer: CharTokenizer512, strict_ctc_length: bool = True
    ):
        super().__init__()
        self.tokenizer = tokenizer
        self.strict_ctc_length = strict_ctc_length

    @staticmethod
    def render_gt_heatmap(
        gt_boxes: List[torch.Tensor],
        gt_roles: Optional[List[torch.Tensor]],
        num_tiers: int,
        H16: int,
        W16: int,
        device: torch.device,
        dtype: torch.dtype,
    ) -> torch.Tensor:
        """
        Hierarchy-Aware Guaranteed-Positive Heatmap Rendering:
        Routes each ground-truth object to its hierarchy tier channel c in {0, 1, 2}
        (0: TABLE/HEADER/FOOTER, 1: TABLE_CELL/KEY/VALUE/LIST_ITEM, 2: Text Lines)
        so containers and their child cells/lines never collide on the same channel.
        Snaps centers to (round(cx), round(cy)) and explicitly clamps peak = 1.0.
        """
        B = len(gt_boxes)
        target_hm = torch.zeros((B, num_tiers, H16, W16), device=device, dtype=dtype)
        ys = torch.arange(H16, device=device, dtype=dtype).view(H16, 1)
        xs = torch.arange(W16, device=device, dtype=dtype).view(1, W16)

        for b in range(B):
            boxes = gt_boxes[b]
            roles = gt_roles[b] if gt_roles is not None else None
            occupied: Dict[int, set] = {t: set() for t in range(num_tiers)}
            for m in range(boxes.shape[0]):
                role_id = int(roles[m].item()) if roles is not None else 4
                tier = PrismOCRv3.role_to_tier(role_id) if num_tiers > 1 else 0
                cx = float(boxes[m, 0].item()) * (W16 - 1)
                cy = float(boxes[m, 1].item()) * (H16 - 1)
                ix = max(0, min(W16 - 1, int(round(cx))))
                iy = max(0, min(H16 - 1, int(round(cy))))
                if (iy, ix) in occupied[tier]:
                    free_cells = [
                        (r, c)
                        for r in range(H16)
                        for c in range(W16)
                        if (r, c) not in occupied[tier]
                    ]
                    if free_cells:
                        iy, ix = min(
                            free_cells,
                            key=lambda rc: (rc[0] - cy) ** 2 + (rc[1] - cx) ** 2,
                        )
                occupied[tier].add((iy, ix))

                w_m = max(float(boxes[m, 2].item()), 1e-3)
                h_m = max(float(boxes[m, 3].item()), 1e-3)
                sigma = max(1.0, math.sqrt(w_m * W16 * h_m * H16) * 0.25)
                gauss = torch.exp(
                    -((xs - ix) ** 2 + (ys - iy) ** 2) / (2.0 * sigma ** 2)
                )
                target_hm[b, tier] = torch.maximum(target_hm[b, tier], gauss)
                target_hm[b, tier, iy, ix] = 1.0
        return target_hm

    @staticmethod
    def gaussian_focal_loss(
        pred: torch.Tensor, target: torch.Tensor
    ) -> torch.Tensor:
        pred = pred.clamp(1e-6, 1.0 - 1e-6)
        pos_mask = (target >= 0.99).float()
        neg_mask = (target < 0.99).float()
        neg_weights = torch.pow(1.0 - target, 4.0)
        pos_loss = -torch.log(pred) * torch.pow(1.0 - pred, 2.0) * pos_mask
        neg_loss = (
            -torch.log(1.0 - pred) * torch.pow(pred, 2.0) * neg_weights * neg_mask
        )
        return (pos_loss.sum() + neg_loss.sum()) / pos_mask.sum().clamp(min=1.0)

    def forward(
        self, outputs: Dict[str, torch.Tensor], targets: List[Dict[str, Any]]
    ) -> Dict[str, Any]:
        heat_probs = outputs["heat_probs"]
        B, C, H16, W16 = heat_probs.shape
        device, dtype = heat_probs.device, heat_probs.dtype
        K = outputs["role_logits"].shape[1]
        T_frames = outputs["char_logits"].shape[2]

        gt_boxes_list = [t["boxes"].to(device=device, dtype=dtype) for t in targets]
        gt_roles_list = [t["roles"].to(device=device) for t in targets]
        target_hm = self.render_gt_heatmap(
            gt_boxes_list, gt_roles_list, C, H16, W16, device, dtype
        )
        loss_hm = self.gaussian_focal_loss(heat_probs, target_hm)

        total_role = torch.tensor(0.0, device=device, dtype=dtype)
        total_box = torch.tensor(0.0, device=device, dtype=dtype)
        total_rel = torch.tensor(0.0, device=device, dtype=dtype)

        ctc_log_probs, ctc_targets, ctc_in_lens, ctc_tgt_lens = [], [], [], []
        unmatched_gt_total = 0
        total_gt_count = 0
        rejected_ctc_samples = 0

        for b in range(B):
            gt_b = gt_boxes_list[b]
            gt_roles = gt_roles_list[b]
            gt_rels = targets[b]["relations"].to(device)
            gt_texts: List[str] = targets[b]["texts"]
            prop_mask_b = outputs["proposal_mask"][b]
            prop_tiers_b = outputs["proposal_tiers"][b]
            M = gt_b.shape[0]
            total_gt_count += M

            matched_m, matched_k = HungarianMatcher.match_proposals(
                outputs["anchor_xy"][b],
                outputs["boxes"][b],
                outputs["node_scores"][b],
                prop_mask_b,
                gt_b,
                gt_roles=gt_roles,
                proposal_tiers=prop_tiers_b,
            )
            num_matched = int(matched_m.numel())
            unmatched_gt_total += M - num_matched

            # Mask out inactive/padded proposal slots (-100 ignore_index)
            role_tgt = torch.full((K,), -100, device=device, dtype=torch.long)
            role_tgt[prop_mask_b] = 0
            if num_matched > 0:
                role_tgt[matched_k] = gt_roles[matched_m]
            role_w = torch.ones(14, device=device, dtype=dtype)
            role_w[0] = 0.25
            if (role_tgt != -100).any():
                total_role = total_role + F.cross_entropy(
                    outputs["role_logits"][b],
                    role_tgt,
                    weight=role_w,
                    ignore_index=-100,
                )

            if num_matched > 0:
                pred_b = outputs["boxes"][b, matched_k]
                gt_b_matched = gt_b[matched_m]
                gt_orient = F.normalize(gt_b_matched[:, 4:6], p=2, dim=-1, eps=1e-6)
                gt_b_norm = torch.cat([gt_b_matched[:, :4], gt_orient], dim=-1)
                l1_box = F.smooth_l1_loss(pred_b, gt_b_norm)
                px1, py1 = (
                    pred_b[:, 0] - pred_b[:, 2] / 2.0,
                    pred_b[:, 1] - pred_b[:, 3] / 2.0,
                )
                px2, py2 = (
                    pred_b[:, 0] + pred_b[:, 2] / 2.0,
                    pred_b[:, 1] + pred_b[:, 3] / 2.0,
                )
                gx1, gy1 = (
                    gt_b_matched[:, 0] - gt_b_matched[:, 2] / 2.0,
                    gt_b_matched[:, 1] - gt_b_matched[:, 3] / 2.0,
                )
                gx2, gy2 = (
                    gt_b_matched[:, 0] + gt_b_matched[:, 2] / 2.0,
                    gt_b_matched[:, 1] + gt_b_matched[:, 3] / 2.0,
                )
                inter = (torch.minimum(px2, gx2) - torch.maximum(px1, gx1)).clamp(
                    min=0.0
                ) * (torch.minimum(py2, gy2) - torch.maximum(py1, gy1)).clamp(
                    min=0.0
                )
                union = (
                    (pred_b[:, 2] * pred_b[:, 3])
                    + (gt_b_matched[:, 2] * gt_b_matched[:, 3])
                    - inter
                    + 1e-6
                )
                total_box = total_box + (2.0 * l1_box + (1.0 - inter / union).mean())

            rel_tgt = (
                torch.arange(K, device=device, dtype=torch.long)
                .unsqueeze(0)
                .expand(4, K)
                .clone()
            )
            rel_tgt[:, ~prop_mask_b] = -100
            m_to_k = {
                int(m_i.item()): int(k_i.item())
                for m_i, k_i in zip(matched_m, matched_k)
            }
            for r_ch in range(4):
                for m_src, k_src in m_to_k.items():
                    m_dst = int(gt_rels[r_ch, m_src].item())
                    rel_tgt[r_ch, k_src] = m_to_k.get(m_dst, k_src)
            if (rel_tgt != -100).any():
                total_rel = total_rel + F.cross_entropy(
                    outputs["rel_logits"][b].reshape(4 * K, K),
                    rel_tgt.reshape(4 * K),
                    ignore_index=-100,
                )

            for m_src, k_src in m_to_k.items():
                text = gt_texts[m_src]
                if not text:
                    continue
                enc = self.tokenizer.encode(text)
                if not enc:
                    continue
                req_frames = self.tokenizer.min_ctc_frames(enc)
                if req_frames > T_frames:
                    rejected_ctc_samples += 1
                    if self.strict_ctc_length:
                        raise ValueError(
                            f"CTC alignment length violation: text of length {len(enc)} "
                            f"requires {req_frames} frames (including repeat blanks), "
                            f"but strip_len={T_frames}. Increase strip_len / "
                            "override_strip_len or split oversized lines."
                        )
                    enc = self.tokenizer.truncate_to_ctc_budget(enc, T_frames)
                    if not enc:
                        continue
                ctc_log_probs.append(
                    outputs["char_logits"][b, k_src].log_softmax(-1)
                )
                ctc_targets.extend(enc)
                ctc_in_lens.append(T_frames)
                ctc_tgt_lens.append(len(enc))

        if ctc_log_probs:
            loss_ctc = F.ctc_loss(
                torch.stack(ctc_log_probs, dim=1),
                torch.tensor(ctc_targets, device=device, dtype=torch.long),
                torch.tensor(ctc_in_lens, device=device, dtype=torch.long),
                torch.tensor(ctc_tgt_lens, device=device, dtype=torch.long),
                blank=0,
                zero_infinity=False,
            )
        else:
            loss_ctc = torch.tensor(0.0, device=device, dtype=dtype)

        total = loss_hm + (total_role + total_box + total_rel) / B + loss_ctc
        proposal_recall = (
            1.0
            if total_gt_count == 0
            else float(total_gt_count - unmatched_gt_total) / float(total_gt_count)
        )
        return {
            "total": total,
            "heatmap": loss_hm,
            "role": total_role / B,
            "box": total_box / B,
            "rel": total_rel / B,
            "ctc": loss_ctc,
            "unmatched_gt_count": unmatched_gt_total,
            "proposal_recall": proposal_recall,
            "rejected_ctc_samples": rejected_ctc_samples,
        }
